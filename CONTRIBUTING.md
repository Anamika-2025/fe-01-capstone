# Contributing

Keep changes focused and follow the conventions already used in the repository.

## Commit messages

Use Conventional Commits in the format `<type>: <short description>`.

Common types include `feat`, `fix`, `docs`, `chore`, `test`, and `refactor`.

Examples:

- `feat: add project navigation`
- `docs: clarify local setup`
- `chore: update editor configuration`

## Checks

Run relevant checks for code changes and include their results when describing the change.
